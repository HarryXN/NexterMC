NexterMC Bot — Source Package

Package contents: current bot source, command cogs, shared utilities, operations files, dependency list, and deployment examples.

Before deployment:
1. Back up the existing VPS project.
2. Upload/replace the source files and folders from this archive.
3. Keep your existing .env file private and unchanged. This archive intentionally does not include it. Use .env.example only as a key checklist; do not upload it as .env without filling in the VPS values.
4. Keep the existing data/ directory and nextermc.db. They contain runtime state and are intentionally not included.
5. Do not upload the local venv, backups, staging folders, or old update archives from the development workspace.
6. Install any newly required packages from requirements.txt and restart the bot service using your normal deployment process.

DiscordSRV is a separate Minecraft plugin and is not included in this bot source archive. Its ConfigVersion is managed by DiscordSRV. To silence its invalid account-link code response, edit InvalidCode in each server's plugins/DiscordSRV/messages.yml; do not replace the DiscordSRV config with the bot's .env.
